# Pokédex Kanto

## Objetivo
Uma Pokédex de página única, em português, com visual vermelho clássico.

## Dados
- Fonte: PokéAPI (pokeapi.co)
- Só os 151 Pokémon de Kanto

## Já funciona
- [x] Busca por nome ou número
- [x] Filtro por tipo
- [x] Status com barras
- [x] Evoluções clicáveis
- [x] Modo escuro
- [x] Botão de Pokémon aleatório
- [x] Lore em português
- [x] Lembra o último Pokémon visto
- [x] Fraquezas por tipo
